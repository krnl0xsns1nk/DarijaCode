# Developer Notes

Quick notes for building and running DarijaCode locally. This will grow as the project does.

## Requirements
- Rust (stable) — install via [rustup.rs](https://rustup.rs/)
- `cargo` (comes with Rust)

## Build

```bash
cargo build
```

## Run

```bash
cargo run -- <arguments>
```

## Run tests

```bash
cargo test
```
