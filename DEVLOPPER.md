# build the project 

```bash
./build.sh # or bash build.sh
```

that produce a binary file called `drj` you can run it by : 

```bash
./drj 
```

## build withwarning and debug 

```bash
./debug.sh # or bash debug.sh
```

that produce a binary file called `run`  you can run it as `./drj`

# source code 

the c files are in `src` folder, while the c headers in `include` folder
